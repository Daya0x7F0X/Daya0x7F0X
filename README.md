## Principles

- **Nur autorisierte Ziele.** Alles hier ist Lern- und Arbeitsmaterial für Engagements mit klarer Autorisierung.
- **Eigene Arbeit.** Skripte, Check-Listen und Notizen stammen von uns — nichts Fremdes wird ungeprüft übernommen.
- **Gepflegt.** Jedes Repo hat klare Struktur, README und Lizenz; Inhalte werden laufend aktualisiert.
